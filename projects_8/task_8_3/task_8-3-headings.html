Курс «Основы веб-разработки»

Этот курс познакомит вас с фундаментальными технологиями создания современных веб-сайтов: HTML, CSS и JavaScript. Курс рассчитан на начинающих без опыта программирования.

1. Введение в HTML

HTML (HyperText Markup Language) — это язык разметки, который описывает структуру веб-страницы. Вы узнаете, что такое теги, атрибуты и как браузер интерпретирует HTML-код.

1.1 Структура HTML-документа

Любой HTML-документ имеет обязательные элементы: DOCTYPE, html, head и body. Правильная структура обеспечивает корректное отображение страницы во всех браузерах.

1.2 Метаданные и заголовок страницы

Метатеги задают кодировку, адаптивность для мобильных устройств, описание для поисковиков и заголовок вкладки. Тег title — единственный обязательный элемент внутри head.

1.3 Текстовые теги и форматирование

Заголовки h1–h6 выстраивают иерархию контента, теги strong и em добавляют смысловое выделение, а HTML-entities позволяют выводить зарезервированные символы.

2. Основы CSS

CSS (Cascading Style Sheets) отвечает за внешний вид страницы: цвета, шрифты, отступы и расположение элементов. CSS позволяет отделить содержание от оформления.

2.1 Селекторы и их типы

Селекторы определяют, к каким элементам будут применены стили. Основные типы: селекторы тегов, классов, идентификаторов и атрибутов.
