🏠 Главная 📖 Обо мне

Это главная страница сайта, оформленного через external CSS. Все стили вынесены в отдельный файл styles.css, который подключён к обеим страницам.

External CSS — это стандарт индустрии. Один файл стилей обслуживает весь сайт целиком. Чтобы изменить дизайн, достаточно отредактировать один файл — изменения применятся ко всем страницам одновременно.

Преимущества внешнего CSS: кэширование (файл загружается один раз), чистый HTML (без стилей), удобство поддержки и единый стиль для всего сайта.
