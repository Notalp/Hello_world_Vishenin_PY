🎨 Эксперимент с Internal CSS

Этот абзац оформлен через Internal CSS (тег style в head). У него заданы цвет текста, размер шрифта, фоновый цвет, внутренние отступы и рамка слева. Internal CSS удобен для одностраничных сайтов и прототипов.

⚡ Это второй абзац. Он красного цвета, на светло-розовом фоне, с рамкой и скруглёнными углами. Шрифт здесь — моноширинный (Courier New). Internal CSS позволяет переиспользовать стили на одной странице.

🌿 Третий абзац: зелёный текст на зелёном фоне, выравнивание по ширине (text-align: justify). Internal CSS — хороший компромисс между inline и external: код чище, чем inline, но всё ещё в одном файле.

  • 📌 Internal CSS задаётся через тег <style> в разделе <head>
  • 🎯 Стили применяются ко всем элементам на странице через селекторы (по тегам, классам, id)
  • ⚠️ При переходе на другую страницу стили нужно дублировать или выносить в external CSS
  • 🚀 Для многостраничных сайтов лучше использовать внешний файл .css
🔗 Наведи на меня мышкой — цвет изменится на красный (hover эффект)
💡 Вся страница оформлена через Internal CSS в теге <style>. Проверь hover на этой ссылке тоже — цвет меняется при наведении.
