🧪 Эксперимент: Cumulative Layout Shift (CLS)

🔬 Инструкция для проведения эксперимента

  1. Нажмите F12 → откройте вкладку Network
  2. В выпадающем списке Throttling выберите Slow 3G (эмулирует медленный интернет)
  3. Поставьте галочку Disable cache (отключить кэш)
  4. Обновите страницу (Ctrl+Shift+R) и внимательно наблюдайте за текстом НИЖЕ каждой картинки
  5. Ожидаемый результат:
    • 🔴 Версия А (без width/height): текст под картинкой "прыгает" вниз, когда картинка догружается
    • ✅ Версия Б (с width/height): текст стоит на месте, картинка появляется плавно

❌ Версия А: Картинка БЕЗ атрибутов width и height

⚠️ Ожидайте "прыжок" контента при загрузке картинки

📝 Абзац 6: Наблюдайте за этим текстом! При загрузке картинки он должен "прыгнуть" вниз, потому что браузер не знал заранее, сколько места зарезервировать под изображение.

📝 Абзац 7: Это явление называется Cumulative Layout Shift (CLS). Google использует его как один из показателей качества сайта. Плохой CLS ухудшает UX и ранжирование.

📝 Абзац 8: Представьте, что вы уже начали читать этот абзац, но в этот момент картинка догрузилась и сдвинула текст вниз — вы потеряли место чтения. Это раздражает пользователей.

📝 Абзац 9: Особенно сильно проблема проявляется на медленном соединении (Slow 3G) и на мобильных устройствах, где картинки загружаются дольше.

📝 Абзац 10: Решение — всегда указывать width и height для изображений, даже если потом вы меняете размер через CSS. Об этом — в Версии Б ниже.

✅ Версия Б: Картинка С атрибутами width и height

✨ Текст должен оставаться на месте, картинка "вырастает" плавно без прыжков

📝 Абзац 5: Temporibus autem quibusdam et aut officiis debitis aut rerum necessitatibus saepe eveniet ut et voluptates repudiandae sint et molestiae non recusandae. Itaque earum rerum hic tenetur.

📝 Абзац 6: Заметили разницу? Этот текст НЕ должен сдвинуться при загрузке картинки. Потому что браузер заранее зарезервировал правильное место.

📝 Абзац 7: Атрибуты width и height сообщают браузеру точные размеры изображения ДО того, как файл загрузится. Браузер оставляет "дырку" нужного размера.

📝 Абзац 8: Даже если вы через CSS задаёте max-width: 100% для адаптивности, атрибуты width/height в HTML всё равно нужны — они задают пропорции (соотношение сторон).

📝 Абзац 9: Современная формула: в HTML указываем фактические размеры файла (width="1920" height="1280"), а в CSS — желаемый размер отображения (max-width: 100%; height: auto;).

📝 Абзац 10: Это один из важнейших принципов Core Web Vitals — метрик, которые Google использует для ранжирования сайтов. Хороший CLS — это здоровый сайт!

📌 Ваши параметры изображения:
  • Файл: images/large-photo.jpg
  • Оригинальный размер: 1920 × 1280 (соотношение сторон 3:2)
  • В Версии Б отображается с width="800" height="533" — пропорции сохранены ✅
