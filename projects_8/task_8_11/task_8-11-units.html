📏 Эксперимент с единицами измерения CSS

px · em · rem · % · vw — наблюдаем разницу при изменении окна и шрифта

🧪 Инструкция для эксперимента

  • 📐 Часть 1: Изменяйте ширину окна браузера (увеличивайте/уменьшайте). Наблюдайте за блоками:
    • 🔹 .size-px — НЕ меняет ширину (фиксированная 200px)
    • 🔹 .size-em — зависит от шрифта родителя (сейчас не меняется при ресайзе)
    • 🔹 .size-rem — зависит от шрифта html (не меняется при ресайзе)
    • 🔹 .size-percent — меняется (50% от родителя)
    • 🔹 .size-vw — меняется (30% от ширины окна)
  • 📝 Часть 2: В <style> найдите html { font-size: 20px; } и измените значение на 16px или 32px. Обновите страницу:
    • 🔹 Блок с rem изменит размер (12 × новый шрифт)
    • 🔹 Блок с px останется 200px
    • 🔹 Блок с em тоже изменится (если изменится шрифт .container)
🔹 Блок 1 — width: 200px px
🔸 Блок 2 — width: 15em em
🔹 Блок 3 — width: 12rem rem
🔸 Блок 4 — width: 50% %
🔹 Блок 5 — width: 30vw vw

📊 Результаты эксперимента

  • 🟢 px (пиксели) — абсолютная единица. Блок НЕ МЕНЯЕТСЯ ни при ресайзе окна, ни при изменении шрифта.
  • 🟡 em — относительная единица. Зависит от font-size родительского элемента (.container). Если изменить шрифт родителя — блок изменит ширину.
  • 🟢 rem — относительная единица. Зависит от font-size корневого элемента <html>. Сейчас html { font-size: 20px; }, поэтому 12rem = 240px.
  • 🔵 % (проценты) — относительно родительского контейнера (.container). При ресайзе окна меняется ширина родителя → меняется и блок.
  • 🟣 vw (viewport width) — относительно ширины окна браузера. 30vw = 30% от ширины экрана. При ресайзе окна блок меняет размер синхронно.

💡 Попробуйте сами: Измените значение html { font-size: 20px; } на 16px или 32px — блоки с rem и em изменят размер, а px — нет!
